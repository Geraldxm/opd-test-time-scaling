# Training engine

This directory contains the `verl` training engine from the public Rethinking-OPD repository used in our experiments. It is based on the open-source `verl` project. A one-step training example is in `../../example_train.sh`.

Names, organizations, contact details, and links retained in source files, packaging metadata, `LICENSE`, and `Notice.txt` belong to the upstream projects and contributors. They are not paper author attribution.
